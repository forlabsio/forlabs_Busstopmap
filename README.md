# 마라톤 노선 관리

전국 버스정류장 위치정보로 마라톤 코스를 만들고, 링크로 공유하고, 인쇄합니다.

![정류장](https://img.shields.io/badge/정류장-64,347개-3182f6) ![지도](https://img.shields.io/badge/지도-MapLibre_벡터타일-3182f6)

## 실행

```bash
python3 -m http.server 8765      # 저장소 루트에서
open http://127.0.0.1:8765/
```

정류장 데이터를 외부 파일(`data/stops.json`)에서 받으므로 `index.html` 더블클릭으로는 열리지 않습니다.
파일 하나로 전달해야 하면 아래 "배포용 단일 파일"을 참고하세요.

## 기능

- **거점 자동 채우기** — 지도에 거점을 몇 개만 찍으면 그 사이 경로의 정류장이 자동으로 선택됩니다.
  간격 슬라이더(100m~1km)로 밀도를 조절하고, 확정 전에 회색 미리보기로 확인합니다.
- **정류장 검색** — `⌘K`로 검색창에 바로 갑니다. 전국 또는 지역별로 찾습니다.
- **노선 편집** — 드래그로 순서 변경, 클릭으로 추가/제거, 구간 누적거리와 총 거리·예상 시간 표시.
- **중간에 끼워 넣기** — 빠뜨린 정류장을 지도에서 클릭하면 경로가 가장 덜 늘어나는 자리에 자동으로
  들어갑니다. 왕복 코스처럼 자동 판단이 애매하면 목록의 `⊕`로 "이 뒤에 넣기" 위치를 고정하세요.
- **실행 취소** — `⌘Z` 또는 툴바 `↩ 실행 취소`로 30단계까지 되돌립니다. 거점 확정처럼 노선을
  통째로 바꾸는 작업도 되돌아갑니다. 화면을 바꿔도 **저장된 노선은 건드리지 않습니다**
  (패널에 "편집 중" 표시가 뜹니다).
- **공유 링크** — 노선을 통째로 담은 링크를 복사합니다. 받은 사람은 **보기 전용**으로 열고,
  원하면 "내 노선으로 복사"로 가져갑니다. 190개 정류장짜리 코스가 약 750자입니다.
- **파일 백업** — 내보내기/불러오기로 노선을 JSON 파일에 보관합니다.
- **다크모드 · 모바일** — 시스템 설정을 따르고 수동 전환도 됩니다. 모바일은 바텀시트로 전환됩니다.
- **인쇄** — 지도 이미지 + 정류장 표 + 총 거리를 A4로 출력합니다.

거리는 정류장을 직선으로 이은 값입니다. 실제 주행 거리보다 짧습니다.

## 저장 방식

노선은 브라우저 `localStorage['marathon-routes']`에 남습니다. 서버도 로그인도 없습니다.
브라우저를 바꾸거나 사이트 데이터를 지우면 사라지므로, 중요한 노선은 **내보내기로 파일 백업**을 받아두세요.
`backups/`에 지금까지의 백업이 들어 있습니다.

## 구조

```
index.html              앱 (마크업)
src/app.js              앱 로직
src/geo.js              거리 계산, 거점 자동 채우기      ← 단위 테스트 있음
src/share.js            공유 링크 압축/복원              ← 단위 테스트 있음
src/store.js            localStorage 저장소              ← 단위 테스트 있음
src/theme.css           Toss 디자인 토큰 + 다크 + 모바일
data/stops.json         정류장 압축 배열 (빌드 산출물)
build.py                CSV -> stops.json 변환
filtered_bus_stops.csv  원본 데이터
legacy/index-v1.html    2026-02 버전 (Leaflet 단일 파일)
```

## 테스트

```bash
npm test                              # 단위 테스트 (node:test)
python3 tests/smoke.py                # 헤드리스 브라우저 스모크
python3 tests/smoke.py --mobile       # 모바일 폭으로
```

스모크 테스트는 로컬 서버가 8765 포트에서 돌고 있어야 하고, Chrome이 설치돼 있어야 합니다.

## 빌드와 배포

```bash
python3 build.py             # data/stops.json 생성 (CSV가 바뀌었을 때)
python3 build.py --single    # dist/index.html — 데이터가 박힌 단일 파일
```

정적 호스팅에 그대로 올립니다. Vercel은 `vercel.json`의 캐시 헤더를 쓰고,
`.vercelignore`가 원본 CSV와 백업·문서를 배포본에서 뺍니다.
